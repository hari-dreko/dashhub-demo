# Dashhub Business

En lokal, interaktiv dashboardskabelon med fiktive data. SOYAs navigation og forside er visuel reference; ingen kundedata eller kode er kopieret.

Åbn `index.html` direkte i en browser, eller kør `python3 -m http.server 8768 --bind 127.0.0.1` fra mappen.

Demoen har overblik, projektsøgning, projektdetaljer, CSV-eksport, illustrerede arbejdsgange og light/dark-tema. Tallene er fiktive og højst 10.000. Tema gemmes lokalt i browseren. Ingen API, login, analyseværktøjer eller eksterne afhængigheder.
